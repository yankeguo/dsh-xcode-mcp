## 自 rc.1 以来的修复

### 高

- **Apple skills 路由提示恢复**：Xcode 导出的 `SKILL.md` 使用 snake_case
  `when_to_use`，旧解析器只读 DSH 的 `whenToUse`，导致 `adopt-c-bounds-safety`
  等 skill 的路由提示被静默丢弃。现在两种拼写都接受并校验类型。
- **backfill 与 `agent/created` 竞态**：旧实现用 `seen` 提前返回，Agent 创建可能
  早于 MCP 工具注册完成。现在复用 in-flight 挂载任务，serial `agent/created`
  会等待同一个任务；新增竞态回归测试。

### 中

- `startupTimeoutMs: NaN` 不再通过 schema（`.step(1)`，同时拒绝小数毫秒），
  避免看门狗立即触发。
- 初次 backfill 期间卸载不再等满 30s 看门狗：新增 `internal/plugin` 卸载观察者、
  abort-aware 看门狗与 `unref()` 定时器；普通 dispose 与 backfill 卸载均有测试。
- `$DSH_HOME` 的空值/空白、`~` 展开和相对路径解析与 DSH 的 `resolveDshHome`
  对齐。
- skills 导出与 bridge probe 现在共用 `config.env` 与自定义 `xcrun` 路径，
  `DEVELOPER_DIR` 等设置不会再让 MCP 与 skills 来自不同 Xcode。
- 不可读的 skill 缓存/`SKILL.md` 不再静默当作空：除 `ENOENT`（读文件时含
  `ENOTDIR`）外都会记录诊断；格式错误与不可读会区分。
- **Xcode 授权流程文档修正**：Xcode 27.2 中连接本身不会触发授权；新 Session 需先
  调用 `XcodeOpenWorkspace`（绝对 `.xcodeproj`/`.xcworkspace` 路径）才会弹出
  Xcode 授权，其他工具在此之前返回 “This agent isn't approved…”。
- 发布状态文档按真实 registry/CI 实况修正（`latest`/`next`、`0.0.0-stage`、
  rc.1 tag run 在 tag 校验步骤失败、GitHub Release 尚未创建），并纠正
  `promote-release.mjs` 的 prerelease edit `--latest=false`。
- peerDependencies 放宽到 rc.1 的宿主版本：cordis `>=4.0.5 <4.2.0`、
  schemastery `>=3.18.5 <3.20.0`，避免 rc.1 profile 的 unmet peer；`engines.dsh`
  仍为 `>=0.2.1-rc.1 <0.3.0`。

### 低

- 声明 `dsh.bundle.platforms: ["darwin"]`，macOS-only bundle 不再在 Linux/Windows
  上被当作可安装；`check-packages` 增加对应不变式。注意 DSH 0.2.1-rc.1 忽略该
  字段，只有 0.2.2+ 才由 Host 强制；rc.1 上仍靠 `xcrun --find mcpbridge` 探针
  失败来跳过挂载。
- README 的 `docs/PUBLISHING.md` 改为 GitHub 绝对链接，npm 包内不再有失效相对链接。
- 修正失败导出的缓存表述、`check-packages` 的运行时依赖注释、`Config` 的 skills
  服务注释、“mounted” 日志、skills 优先级说明、`startupTimeoutMs` 整数文档。


首次在 Session 内使用 Xcode 工具时，先调用
`mcp__xcode__XcodeOpenWorkspace`（项目绝对路径）并在 Xcode 中批准授权；在此之前
其他 Xcode 工具会返回未授权错误。Xcode 需处于运行状态。

## 已知限制

- **创建时决策**：发现与挂载只在 Agent 创建时执行；`workingDirectory.set` 不会
  重新评估，旧项目的工具/skills 会附着到该 Agent 重建为止。瞬时失败不重试。
- **残余竞态**：插件激活时若某个 Agent 的 `agent/created` 派发已开始（监听器
  快照已定），backfill 可能无法被创建路径等待；DSH 没有 announcement barrier。
- **config restart**：Cordis restart 不触发 `internal/plugin`；restart 时若
  backfill 挂载卡住，仍需等看门狗。
- **非 abort 子步骤**：bridge probe 有 10s 上限；项目树在挂死的网络卷上仍可能
  拖慢卸载。
- **只识别 `*.xcodeproj`**：`.xcworkspace`-only 仓库不会挂载（当前公开契约）。
- **自定义 launcher**：非默认 command/args 跳过可用性预检，由 mcp-client 自行
  验证。
- `toolCallTimeoutMs` 未暴露；大构建可在自定义 mcp-client 设置中调整。
- 没有 Web UI；唯一的文件系统写入是自身的 skills 缓存目录。
